# Protocol TVL Implied Odds Expected Verdict Net $/h

Click a row for the detail view: value breakdown, nearest traded comps, sensitivity matrix, and the farm plan with costs.

How to read this board. Implied is what the token would be worth at launch if the protocol's record stayed as it is (size curve fitted on 128 traded comps). Odds is the fitted probability a protocol with this TVL, age and category records a token. Expected = implied × odds × 10% farmer share. The verdict prices a reference $1,000 / 12-week farm: FARM when it nets over $25 after gas, THIN when it nets over $0, else SKIP. Big protocols rank high on expected value but dilute a small farmer — sort by Net $/h to see the other side.

Implied values are this entry's own claim, never make.fun's. A protocol "records no token" in the snapshot; that is DefiLlama's record, not proof it has none. Model, validation and assumptions: 0-research.md in this dashboard. No network: every number on this page comes from the sealed snapshot.
